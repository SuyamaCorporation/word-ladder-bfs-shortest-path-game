# ワードラダー BFS最短経路言語ゲーム

1文字ずつ変えながらスタート単語をゴール単語に変換する「ワードラダー」ゲームです。約300語の4文字英単語データベースを内蔵し、BFSで最短経路を計算してプレイヤーの手数と比較します。制限時間なし/60秒/90秒/120秒から選択可能で、最短ヒントの表示/非表示も切り替えられます。変更した文字はオレンジ色でハイライトされ、辞書にない単語や1文字以外の変化はエラー表示されます。

## 使い方

表示されたスタート・ゴール単語を確認し、入力欄に次の単語を1文字だけ変えて入力してEnterまたは「確定」を押してください。ゴールに到達したらクリアです。
